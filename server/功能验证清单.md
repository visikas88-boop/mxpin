## 🚀 下一步操作

### 立即行动

1. **创建管理员账号**
   ```bash
   cd server
   node create-admin-hash.js
   # 复制生成的 SQL 语句到数据库中执行
   ```

2. **启动服务**
   ```bash
   # 方式1：使用启动脚本
   ./启动服务-管理后台.bat
   
   # 方式2：手动启动
   cd server && node src/index.js
   cd web && npm run dev
   ```

3. **登录测试**
   - 访问 http://localhost:3000/admin/login
   - 使用创建的管理员账号登录
   - 测试各项功能
