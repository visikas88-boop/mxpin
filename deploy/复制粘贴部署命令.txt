==========================================================
VideoFlow Pro 一键部署命令（复制粘贴到SSH终端）
==========================================================

第一步：SSH登录到Vultr服务器
------------------------------
在Windows PowerShell或Git Bash中执行：

ssh root@45.32.65.132

（输入密码后回车）


第二步：复制以下全部命令，粘贴到SSH终端并回车
------------------------------

#!/bin/bash
set -e

echo "========================================="
echo "VideoFlow Pro 完整部署开始"
echo "========================================="

# 1. 更新系统
echo ">>> [1/12] 更新系统..."
apt-get update -qq
apt-get install -y git curl wget

# 2. 创建部署目录
echo ">>> [2/12] 准备部署目录..."
mkdir -p /var/www/videoflow-pro
cd /var/www/videoflow-pro

# 3. 克隆或更新代码
if [ -d ".git" ]; then
    echo ">>> [3/12] 更新代码..."
    git fetch origin
    git reset --hard origin/main
else
    echo ">>> [3/12] 克隆代码仓库..."
    git clone https://github.com/visikas88-boop/mxpin.git .
fi

echo "当前版本: $(git log -1 --oneline)"

# 4. 检查并执行部署脚本
if [ ! -f "deploy/quick-deploy.sh" ]; then
    echo "❌ 错误: 部署脚本不存在"
    exit 1
fi

echo ">>> [4/12] 执行完整部署..."
chmod +x deploy/quick-deploy.sh
bash deploy/quick-deploy.sh

echo ""
echo "========================================="
echo "✅ 部署完成！"
echo "========================================="
echo ""
echo "访问地址: http://45.32.65.132"
echo "管理员: admin@videoflow.pro / admin123"
echo ""
echo "查看服务状态: pm2 status"
echo "查看后端日志: pm2 logs videoflow-backend"
echo ""

==========================================================
故障排查
==========================================================

如果部署失败，请检查：

1. 查看详细错误日志：
   pm2 logs videoflow-backend --lines 50

2. 检查数据库连接：
   sudo -u postgres psql -l | grep videoflow_pro

3. 检查Nginx配置：
   nginx -t

4. 查看系统日志：
   journalctl -xe

5. 重新执行部署脚本：
   cd /var/www/videoflow-pro
   bash deploy/quick-deploy.sh
