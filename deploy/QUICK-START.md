## 立即执行（3步完成）

### 步骤1：获取Vultr API密钥
访问：https://my.vultr.com/settings/#settingsapi
点击 "Add API Key" 并复制

### 步骤2：在PowerShell中设置
```powershell
$env:VULTR_API_KEY = "粘贴你的API密钥"
```

### 步骤3：执行自动部署
```powershell
cd F:\Aipost\deploy
.\vultr-auto-deploy.ps1
```
